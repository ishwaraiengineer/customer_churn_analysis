# Customer Churn Analysis

## Project Overview
This project analyzes customer churn to understand why customers leave a subscription-based business and identify opportunities to improve customer retention.

## Objectives
- Calculate the overall customer churn rate.
- Analyze churn by plan type and location.
- Understand customer retention and subscription trends.
- Identify revenue at risk and customer lifetime value (CLTV) lost.
- Generate actionable business insights.

## Database Tables
The project uses three tables:
- `db_customer` — customer demographics and details.
- `db_subscription` — subscription plans, charges, and churn information.
- `db_support` — customer complaints, escalations, and support data.

## Tools & Technologies
- Python
- SQL
- Pandas
- Jupyter Notebook
- Data Analysis and Visualization

## Key Insights
- Customer churn rate: 28.6%
- Retention rate: 71.4%
- Revenue at risk: 74
- CLTV lost: 2,047
- Monthly vs. annual churn: 55.6% vs. 8.3%

*Note: Figures are based on the current analysis and use the project's original units.*

## Business Recommendations
- Investigate the high churn rate in Karnataka.
- Review pricing and subscription changes.
- Prioritize high-risk customers for retention campaigns.
- Improve complaint resolution and customer support.
- Encourage suitable customers to consider annual plans.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Ensure the required database file is available.
5. Run the notebook cells in order.
